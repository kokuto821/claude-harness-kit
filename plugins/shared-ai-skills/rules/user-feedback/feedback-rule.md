# ユーザーフィードバックのルール化

## 原則

ユーザーから指摘・訂正・改善提案を受けたとき、それが繰り返し発生しうるパターンであればルール化を検討する。

## 判断基準

以下のいずれかに当てはまる場合、ルール化を提案または実施する:

- 同じ誤りを再び犯す可能性がある
- 判断の軸になる原則として明文化できる
- 既存ルールの抜け穴や例外を埋める内容である

一度限りのコンテキスト固有の指摘はルール化しない。

## 手順

1. 指摘の内容を受け取る
2. 上記の判断基準に照らす
3. ルール化すべきと判断したら、適切なトピックの `rules/<topic>/` に追記または新規作成を提案する
4. ユーザーの承認を得てから書き込む
