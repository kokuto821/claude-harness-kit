# ステッパー
- 複数のステップに分かれた工程を示すパーツ
  - ページが分かれている入力フォームやプロセスフローで使われる
    - 会員登録
    - オンライン購入の手続き
  - 進捗を視覚的に伝えることで、次に何をするべきかが明確になる
  - 入力途中の離脱を防ぐ役割
  - 全体の流れを直観的に理解
## 原則
- 全体の流れを明確に示す
  - 進捗状況が正確に表示される
- 画面幅が狭いデバイスの場合は横並びのステップが収まりきらない場合がある
  - スライド可能なデザインとするか、分数での表記を検討する
  - 3~6ステップでは全体の流れを示す矢印を追加し、完了までの距離感を図で視覚的に伝える
  - 7~の長い工程では分数での表記も有効
