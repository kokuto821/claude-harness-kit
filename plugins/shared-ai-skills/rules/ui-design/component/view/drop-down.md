# ドロップダウンメニュー
- クリックすると複数の操作メニューがリスト状に展開する機能
  - 操作が多く、レイアウトが収まらないときに使われる
  - 多数あるボタンをコンパクトに整理する
## 原則
- ボタンの右側に下矢印を置き、そのボタンから派生する機能や関連する機能をメニューとして並べる。
- 操作が多くレイアウトに収まらない場合に使う
- ボタンの優先度を弱めたいときに使う
  - ドロップダウンは、メニューを開く→操作メニューを押すという2段階の操作になる
  - 通常のボタンに比べ、操作負荷が高い
- コンテキストメニューは使わない
  - Webブラウザでは右クリックを使って操作する印象が少ないため、コンテキストメニューに同様の役割のメニューは「...」で表示する
## 例
- 「メール送信」のボタンから「予約送信日時」を選択する
- 「削除」などユーザーにあまりさせたくない操作の場合は、メニューの数が1件だけでもあえてドロップダウンメニューの中に配置するという手法もある
