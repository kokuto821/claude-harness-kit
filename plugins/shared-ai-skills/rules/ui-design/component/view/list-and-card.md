# リストとカード
- 一覧画面に複数の画面が並ぶ
  - 一覧からアイテムを選択して、何かしらの操作を行うことが一般的
## 原則
- リストやカードはユーザーが情報を見つけやすいようにシンプルにする
  - 見つけやすさを優先する
- 縦一列に並ぶリストビュー
  - アイテムを多く並べることができる
  - 文字情報メイン
  - 高さを抑えることができる
  - アコーディオンに派生することができる
- 複数列でカードが並ぶグリッドビューがある
  - カード型で画像を大きく見せることができる
  - リストビューに比べ直観的に探せる
- リストとグリッドの切り替えを可能にする
  - トグルボタンを置くことでユーザー好みで選ぶことができるため、一人ひとりに合わせたUIにできる
- ソートをする際はセレクトボックスを用いる
