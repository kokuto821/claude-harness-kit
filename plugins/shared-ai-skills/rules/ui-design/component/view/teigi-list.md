# 定義リスト
- データの情報を画面に表示するリスト

## 原則
- 項目名と値をセットで表示する
- 縦並びの定義リスト
  - メリット
    - 画面幅が狭い場所、特にモバイルで適している
    - デスクトップの場合は複数個を並べたときでも見やすい
  - デメリット
    - 横並びと比べて高さが出やすくなる
      - 項目数が多いとページが長くなる
- 横並びの定義リスト
  - メリット
    - 縦方向にコンパクトにできるのでデスクトップアプリでのレイアウトに適している
    - 2列で表のような形となり1対1の関係がわかりやすくなる
  - デメリット
    - 画面幅が狭い場所では使いにくい
      - モバイルでは適さない
- 入力画面とレイアウトをそろえる
  - 設定画面やフォームなどでユーザーが入力したデータの表示に適している
