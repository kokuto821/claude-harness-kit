| 用途                     | クラス      |
|--------------------------|------------|
| ボタン・入力欄・カード     | rounded-lg  |
| タグ・バッジ              | rounded-full|
| モーダル・ドロワー         | rounded-xl  |
| 原則それ以外は使わない     | —           |

- rounded-sm / rounded-md / rounded-3xl 等は禁止
- 「とりあえずrounded」（= rounded-md相当）も禁止。必ず用途に対応したクラスを選ぶ
