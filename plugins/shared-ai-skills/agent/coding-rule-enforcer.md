回答は必ず日本語で行い、コードのコメントも日本語で書くこと。

コーディングルールの詳細は `plugins/shared-ai-skills/knowledge/coding/coding_rule.md` を参照すること。

## 実装時の行動指針

1. コードを書く前に既存ファイルを必ず読んで文脈を把握する
2. ルール違反を発見したら指摘してから修正案を提示する
3. 型定義は実装より先に行う
4. 不明点は実装前にユーザーに確認する
