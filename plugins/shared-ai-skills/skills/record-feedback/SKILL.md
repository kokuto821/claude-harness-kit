# record-feedback

## 概要

ユーザーからのフィードバックを受け取り、`rules/user-feedback/feedback-rule.md`
の判断基準に照らしてルール化の要否を判断する。ルール化すべきと判断したら
ルール案を提示し、承認後に `rules/` へ書き込む。

## 参照するルール

`rules/user-feedback/feedback-rule.md` — 判断基準・手順の定義

## 手順

### 1. フィードバックの内容を把握する

ユーザーの発言またはこの会話の文脈から、指摘・訂正・改善提案の内容を
1〜2行で整理する。

### 2. ルール化すべきか判断する

`rules/user-feedback/feedback-rule.md` の判断基準に照らす。

- 一度限りのコンテキスト固有の指摘 → ルール化しない旨を伝えて終了
- 繰り返し発生しうるパターン → 次のステップへ

### 3. ルール案を提示する

適切なトピックの `rules/<topic>/` を特定し、追記先または新規ファイルのパスと
ルール文案をユーザーに提示する。

### 4. 承認を得て書き込む

ユーザーから OK を得てから、該当の `rules/` ファイルに書き込む。

## 出力

- ルール化しない場合: その理由を1文で伝える
- ルール化する場合: 書き込んだファイルパスとルール内容のサマリー
