# stock-trading-kit

株取引の情報分析をサポートするプラグイン。銘柄・市場・ポートフォリオに関するエージェントとスキルを管理する。

## ディレクトリ

- `skills/` … Claude Code のスキル（`SKILL.md`）
- `rules/` … Claude が常に従うルール
- `documents/` … 仕様・調査ドキュメント（reference / research）
- `knowledge/` … 分析で得た経験・知見メモ（architecture / market）
- `agent/` … サブエージェント定義
- `template/` … スキル・エージェント等のテンプレート
- `.claude-plugin/` … このプラグインのマニフェスト
