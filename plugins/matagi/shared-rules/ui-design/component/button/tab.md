# tab
- 情報を整理しつつ複数のセクションやコンテンツを切り替える
- 一覧画面の絞り込みや並列の情報を切り替え
## 原則
- バッジを活用して重要情報を強調する
  - タブは複数あるが、そのうちの１つしか開いてもらえないため
- タブを使わない方がよいパターン
  - 全体の情報量が少ない場合
    - すべての1枚のページで表示するほうが情報が確認しやすくなる
  - 各タブの情報が少ない場合はタブをやめるか情報の分け方を工夫する
  - タブ数が増えすぎると横スクロールが必要となり横断的に移動しにくくなる
    - 垂直タブの使用も検討する
## 例
- 新着メッセージや未処理タスクの件数を示すバッジを表示する
