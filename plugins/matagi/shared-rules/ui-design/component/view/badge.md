# badge
- 項目に特定の状態や数値を付与し、ユーザに通知するためのパーツ
## 原則
- バッジを消したいという心理に働きかける
  - 未読メッセージやアクションが必要な項目を目立たせることでユーザーに迅速な対応を促せる
- バッジを消すアクションを明確に伝える
  - 何をしたらバッジが消えるのか
  - バッジを消す方法がわからないとユーザーは強いストレスを抱えるため、わかりやすい設計を心がける
- バッジは本当に必要な箇所だけにつける
  - 必要以上につけることで本来の役目である「注意を引く」効果が失われる
## 例
- 通知バッジが未読メッセージを示している場合、遷移先のページで未読と既読がはっきり区別できるデザインを用意する
- 未完了のタスクを示すバッジの場合、未入力の項目や達成するべきアクションを明確に示すデザインを用意することでユーザーは次の行動を直観的に予想しやすくなる。
