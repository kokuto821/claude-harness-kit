# table
- 表形式でデータを表示する
  - リストやカードに比べると情報が均一に見える
  - テキストが整理されて並ぶため情報を見やすい
  - 見出しを使って列ごとにソートをしたりできる
  - 列の並び替えができる
## 原則
- 特にデスクトップアプリケーションでリストやカードと同じく、アイテムを並べる際に用いる
- 極力横スクロールは避ける
  - 閲覧負荷を高めるため 
    - 情報が隠れる
    - 右端にあるボタンが押せなくなる
- 列数を減らす、改行をなくすなどして見やすくする
  - 一定の幅を超えたときは末尾に「...」を置き、省略表示することを推奨
- テーブルならではの機能を活かす
  - 列名をクリックしてソート
  - 左上のチェックボックスで一括チェック
  - 特定の列の色を変える・強調する
