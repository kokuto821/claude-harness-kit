# メッセージアラート
- ほかの要素よりも目立たせ、ユーザーに情報を伝えるためのパーツ
## 原則
- 一般的には以下の4種類が使われる
  - Information
    - 青
  - Success
    - 緑
  - Warning
    - 黄色
  - Danger
    - 赤
- お知らせとして使うアラートとフィードバックとして使うアラートを分ける
  - お知らせ
    - 画面上に最初から表示し、システムからのお知らせや操作上の注意点を記載する
    - 押下することで詳細な情報を確認できるリンクとする場合もある
  - フィードバック
    - ユーザーの操作に対する回答として表示する
    - ユーザーの実行操作後に「成功」「失敗」を表示するようにする
