# 見出し
- 直後に続くコンテンツのタイトル・要約などを表記するテキスト
## 原則
- デザイン作成時のパーツとしてはh2以降を用意する
  - h1は画面タイトルとしてページヘッダーに記載することが大半のため
- 大きい見出しから順番に小さい見出しを利用することで、情報の階層をわかりやすく整理する
  - 〇 h2→h3→h4
  - × h3→h2
  - ナビゲーションによってh2の見た目を複数用意してパターンを整理するなど、直後のコンテンツの大きさに合わせた見出しの見た目を考えることも重要
- Webサイトの場合は見出しで目を引く必要があるため、大きい文字サイズで色や装飾を工夫し、デザイン性を高める
- アプリケーションの場合は見出しの文字も小さく、色も黒やグレーで控えめにすることで、機能の操作部分を強調する必要がある。
