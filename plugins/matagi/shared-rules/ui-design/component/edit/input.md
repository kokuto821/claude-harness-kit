# input
- 押下することで選択状態となり、その状態でキーボード操作を行うと文字を入力することができる。
## 原則
- インプットは基本的に1行だけを入力する際に使う
  - 改行を含む複数行を使う際は「テキストエリア」を使うようにする
- 入力内容と画面全体のレイアウトのバランスを見て、ちょうど良い落としどころを考えるようにする
  - 入力内容によって幅を調整する
    - 入力前に入力する文字の長さを想像させることでスムーズに操作を進められる。
  - 画面全体のレイアウトのバランスも考慮する
    - モバイルでは幅をいっぱいにした方がいい場合もある
    - デスクトップでも幅をそろえることで整列した見やすいレイアウトにすることができる
- 参照画面は登録画面と同じ見た目にならないようにする
  - 入力可能な状態と誤認してしまう
    - disableであっても同様
  - 参照画面では通常のテキスト（定義リスト）を置くようにし、確定されたデータであることがわかるようにする
