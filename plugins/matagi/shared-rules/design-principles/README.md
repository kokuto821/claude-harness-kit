# design-principles

コード設計の普遍的な原則（DRY・SRP・関心の分離・疎結合/高凝集）を置く場所です。

言語・フレームワークに依存しない設計の土台をまとめ、実装・テスト・レビューの各ルールやエージェントはここを参照します。原則の定義はこのディレクトリを唯一の正とし、各所で再掲しません。

| ファイル | 内容 |
|---------|------|
| `design-rule.md` | DRY・SRP・関心の分離・疎結合/高凝集 の定義と判断基準（唯一の正） |

周辺の設計法則・原則・比喩の用語集は判断基準ではないため、`documents/reference/design/design-principles-glossary.md` に置く。
