# プレースホルダー
- 入力値に何も値が入っていないときに、薄い文章でテキストを表示することで、ユーザーの文字入力をサポートする
  - 細かいがアプリケーションの使い勝手を大幅に向上できる
## 原則
- 入力例を記載する
- 項目名を記載することでコンパクトに
  - 項目名をインプットに入れることで外側に項目名を置く必要がなくなる
- 検索ボックスではどんなキーワードで検索できるのかを記載する
  - 検索対象をユーザーに事前に知らせることができる
  - 複数の検索キーがある場合におすすめ
  - 入力後に項目名がわからなくなってしまう点に注意が必要
- 入力時の注意はプレースホルダーに記載しない
  - 入力し始めるとチェックできなくなるため
  - 該当する場合は入力ボックスの外

## 例
- 入力の例を記載する
- 入力項目名自体を記載する
- 「漢字」と「かな」の入力欄があった場合
  - 「山田」「太郎」「やまだ」「たろう」と入力されている
- 数字の場合は桁数をあらかじめ表現する
