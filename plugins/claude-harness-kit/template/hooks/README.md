# hooks テンプレート

Claude Code のフック機能で実行するスクリプトのひな形を置くディレクトリ。

## フックとは

特定のイベント（ツール実行前後・セッション終了など）に自動で走るシェルスクリプト。
Claude の判断に頼らず、**強制的な制約**を設けたいときに使う。

## 主なイベント種別

| イベント | タイミング |
|----------|-----------|
| `PreToolUse` | ツール実行前（ブロック・書き換えが可能） |
| `PostToolUse` | ツール実行後（ログ・後処理） |
| `Stop` | Claude の応答完了後 |

## ここに置くもの

- 禁止コマンドをブロックする `.sh`
- 実行ログを記録する `.sh`
- 出力を自動整形・検証する `.sh`

## 参考

設定は `.claude/settings.json` の `hooks` セクションに記述する。
