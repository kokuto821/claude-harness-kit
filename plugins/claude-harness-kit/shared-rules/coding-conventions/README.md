# coding-conventions

コーディング規約のルールを置く場所です。

実装時に守るコーディング上の取り決めを `coding-rule.md` に、テスト固有の取り決めを `test-rule.md` に、TDD の方法論を `tdd-rule.md` に、coding/test-coding/coding-review スキルの domain 判定・委譲基準を `domain-classification-rule.md` にまとめています。

| ファイル | 内容 |
|---------|------|
| `coding-rule.md` | 命名・TypeScript・定数・スタイリング・関数設計・hooks など実装全般 |
| `test-rule.md` | テストの命名・構造・分割・ヘルパー・AAA パターン |
| `tdd-rule.md` | TDD の核心哲学・List-Red-Green-Refactor-Commit サイクル・コーディング標準 |
| `domain-classification-rule.md` | coding / test-coding / coding-review スキルの domain（frontend/backend等）判定基準と、専用サブエージェントが無い場合の委譲方針 |
