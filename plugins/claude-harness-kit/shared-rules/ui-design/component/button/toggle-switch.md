# トグルボタンとスイッチ
- トグルボタンとスイッチは状態の切り替えを行う
- 設定画面やモードの切り替えで使われる
## 原則
- トグルボタン
  - 複数の状態を表す
  - 押下で別の状態に切り替わる
  - 異なる状態や機能の切り替え
  - タブのように利用可
  - オン/オフの2つの状態を切り替えるのにも使える
    - ただしスイッチよりスペースをとる
  - フリップフロップ問題
    - 現在の状態を示しているのか、押下後の状態を示しているのかわからない問題
    - オンオフの状態が視覚的に明確になるようラベル付きのボタンを左右に並べる
- スイッチ
  - オン/オフの2つの状態を切り替える
  - トグルボタンより即時性が高い
    - すぐに機能が有効化/無効化されたことが伝わる
- チェックボックス
  - スイッチと同様にオン/オフの2つの状態を切り替え
  - すぐに有効化される場合もあれば、保存しないと有効化されない場合がある
