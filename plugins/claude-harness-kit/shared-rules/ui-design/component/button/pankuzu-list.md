# パンくずリスト
- アプリ内で今いる画面がどの画面からたどり着いたのか、どのカテゴリ内にいるかを把握できるパーツ
- 1つ前や2つ前の操作に戻りたくなった場合の便利なパーツ
## 原則
- 画面数の多いサイトやマニュアルページでは利便性が高いため必ず置くようにする
- 階層が浅いアプリであれば、不要
  - ナビゲーションのカレントがあれば現在地を理解可能なため
- 画面タイトル・ナビゲーション・パンくずリストの文言は必ずそろえるようにする
  - 同じオブジェクトを指していることがユーザーに明確に伝わるようにすることで、画面の導線、アプリ内の構成がわかりやすくなる
- パンくずリストにはリンクを設置して上位階層の画面に戻れるようにする
- 現在地とリンクをわかりやすくする
  - 末尾にある現在地はクリックできないようにして太字にする
  - 前階層は下線を引く
