# ページャーと件数カウンター
- 情報量が多い場合にユーザーに見えている範囲を表示する
  - ページャーで表示量を抑制することで表示速度を速めることができる
## 原則
- 全体のボリュームがわかるようにする
  - 件数や並び順が見えることでユーザーが次の操作を考えやすくなる
- もっと見るボタンor無限スクロールは使う場面を考える
  - シンプルな操作でユーザーも簡単に扱うことができる
  - SNSやチャット等リアルタイムで情報が更新されるUIに向いている
  - 「全体量がわからない」「画面遷移後に一覧画面に戻ってきたときに元の位置に戻りにくい」というデメリットがある
  - 一般的な一覧であればページャーを推奨
- チェックボックスを使った一括選択に注意
  - 複数ページにまたがる要素をチェックボックスで一括選択した場合、「現在のページで選択したアイテム」だけが対象なのか、「全ページで選択したアイテム」が対象なのかがわかるようにする。
  - 「〇件選択中」、補足のテキストを入れる等
