# text-link
- <a>に該当するパーツ
- 画面遷移したり、外部のサイトにリンクする
- 文章内の補足や引用元を示す
## 性質
- 下線をつけるとテキストリンクと認識されやすい。
  - 画面内に多数のテキストリンクが登場する場合
- 下線が多くあると複雑な印象を与えて印象になる
  - 対策として、最初は文字色を変えた状態にして置き、オンマウス時だけ下線が出るようにすると、リンクであることをユーザーに示しつつ、複雑な印象を弱めることができる
## 原則
- ボタンに比べて存在感が控えめで目立ちにくく、画面内で重要度・優先度を低いものに対して利用
- 外部リンクなどにはアイコンをつける
  - テキストリンクを押した後の挙動をわかりやすく伝えることができる
  - 「外部のサイトにリンクする」「新規ウィンドウでページが開く」「メールが起動する」等
- リンクテキストの内容
  - ×詳細はこちら
    - リンク先の内容が明確に伝わらない
  - 〇リンク先の画面名を明示
  - ユーザーに伝わりやすい名称になっている
