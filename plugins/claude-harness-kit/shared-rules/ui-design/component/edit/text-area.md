# text-area
- 複数行のテキスト入力を可能にするパーツ
  - コメントや問い合わせフォーム、自由記述欄の入力欄など
## 原則
- 長文の場合はスクロールバーで表示する
- 内容に応じて入力欄の高さが変化するものもある
- インプットと同様にどのくらいのボリュームの文章を入れる欄かユーザーが想像できるようにする必要がある

## 例
- ブログやメールアプリなどの文字量が多い入力欄は広いエリアとし、チャットアプリなどの簡易な会話ツールであれば小さいサイズにする
- コンパクトなまま長文入力させる場合は、右下のつまみでリサイズ可能にしたり、テキストエリア内にスクロールバーを設置する
