# tooltip
- アイコンやボタンなどの要素にカーソルを合わせることで表示される小さなポップアップ
  - PC画面で補足情報や操作方法を伝えるために使用される
  - 初めて使用する機能やわかりにくい要素を補足する場面でも有効
## 原則
- オンマウスで表示するツールチップは簡潔に情報を提供する
  - 多用はしない
  - ユーザーが疑問に思う可能性が高い要素に対して、補足情報を簡潔に伝えることができる。
  - 意味があいまいなアイコンや操作の結果がわかりにくいボタンに対して効果的
  - わかりやすい要素の場合はツールチップ不要
- ツールチップ内の情報量は必要最低限に抑える
- 省略された文字を補完する
  - メールのタイトル等レイアウト上の都合で文字情報が省略された場合、全文を表示する方法が有効
  - 表示するエリアに注意して設計する
- クリック・タップで表示する補足説明のツールチップ
  - 固有名詞や専門用語、入力欄の補足説明する場面で有用
  - 項目の近くに「？」アイコンや情報アイコンを設置してクリックさせる仕組み
    - 長い説明を表示する場合に有効
    - 正方形に近い形状を用意し、詳細はリンクを張る
    - 閉じるボタンを右下に置く
