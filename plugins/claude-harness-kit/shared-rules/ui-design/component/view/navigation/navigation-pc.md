# PCアプリのナビゲーション
## 原則
- ナビゲーションはヘッダーor左サイドバーに配置
  - ヘッダーはToC向けの消費者向けのサイト等レスポンシブ設計のサイトでよくみられる
  - 左サイドバーは業務系アプリケーションで多く使われる。縦スクロールできるので多くの情報を載せられる
- カレント状態を必ず用意する
  - どの場所にいるかをユーザーに示し、迷わせないUIにするため
- ナビゲーションの階層化・入れ子構造
  - 親子関係がわかるように、レイアウトや強弱を工夫する
  - 例
    - 親ヘッダーでカテゴリを示し、子のサイドナビゲーションでカテゴリ内の現在位置を明確にする
    - 親のサイドナビゲーションに色を敷いて画面の左側に配置し、子のサイドナビゲーションは右側に配置して階層関係を明確にする
- メニュー数を多くしすぎない
  - 多すぎるとできることを確認しきれず迷うため
  - 目安としてメニューの数は7個以内
    - どうしても減らせない場合は、ナビゲーションをドロップダウンなどで階層化する
