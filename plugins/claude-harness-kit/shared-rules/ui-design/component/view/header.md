# header
## 原則
- アプリケーション全体に関わるような横断的な情報や機能が配置される
  - 検索
    - アプリケーション全体の検索
  - 通知
    - どの画面からも通知に気づくことができる
  - ロゴ
    - 今何を操作しているのか
  - コンテンツの登録ボタン
    - メールアプリであればメール新規作成ボタンなど、そのアプリの主要コンテンツの登録を行うボタン
  - ヘルプメニュー
    - 操作説明マニュアルのリンク
- スクロール時にヘッダーを固定するかどうか  
    - ヘッダーの機能にアクセスしやすくなる
    - 画面が狭くなる
  - モバイルの場合はヘッダーを置かない場合がある
    - 画面が狭く、簡潔に見せるため
    - ボトムナビゲーションに配置
