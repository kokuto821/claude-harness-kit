# トースト
- ユーザーが行った操作のフィードバックとして用いる
- 表示後、しばらくすると自動で非表示になるため、操作を中断することがない
## 原則
- 表示する内容は成功を表す短いテキストで利用する。
- エラーはユーザーが読む必要があるため、自動で消えてしまうトーストは適していない
- ユーザーが気づきやすい場所に表示する
  - 直前の操作ボタンの位置の近くか画面の上部に表示することが一般的
  - モバイルでは画面の下部に操作ボタンがあるため下からトーストを出すことが多い
- トーストとメッセージアラートのSuccessはほぼ同じ
  - トーストは自動で消えるが、アラートはユーザーが自分で消す必要がある
## 例
- 保存しました
- 送信しました
