# スキル・エージェント テンプレートルール

## テンプレートの置き場所

| 種類 | テンプレートパス |
|------|----------------|
| スキル | `plugins/claude-harness-kit/template/skills/SKILL.md` |
| サブエージェント | `plugins/claude-harness-kit/template/agents/AGENT.md` |

## スキルテンプレート

### フロントマター

最小構成は `name` と `description` のみ。他は必要なときだけ追加する。

```yaml
---
name: skill-name        # ディレクトリ名と一致させる（kebab-case）
description: >          # 最重要。自動起動トリガー。要点を先頭に書く
  ...
---
```

オプションフィールド:

| フィールド | 追加するとき |
|-----------|-------------|
| `when_to_use` | description を補完するトリガー条件がある場合 |
| `allowed-tools` | 使用ツールを明示的に制限したい場合 |
| `disable-model-invocation: true` | 副作用があるタスク型で手動起動のみにしたい場合 |
| `context: fork` | 別コンテキストで隔離実行したい場合 |

### 本文

> **スキル本文構成の定義はここを唯一の出典とする。** テンプレート本体（`template/skills/SKILL.md`）はこれを体現し、`create-skill` はこれを参照する。各所で構成を文章で再記述しない。

- **500行未満**を目安に保つ（ロード後セッション中ずっとコンテキストに残るため）
- 詳細なリファレンスは別ファイルに分離する
- 構成: 「概要」→「ルール」→「手順」→「出力」が基本

| ブロック | 内容 | 省略 |
|---------|------|------|
| 概要 | 何をするスキルか（1〜2行） | 不可 |
| ルール | このスキルが従う規約・判断基準。本文に直書きせず `rules/` / `reference/` を参照する（[[externalization-rule]]） | ルールが無いスキルは省略可 |
| 手順 | 実行ステップ | 不可 |
| 出力 | ユーザーに返す形式 | 不可 |

### タスク型 vs 参照型

| 種類 | 判断基準 | ポイント |
|------|---------|---------|
| タスク型 | デプロイ・コミットなど副作用あり | `disable-model-invocation: true` で手動起動に |
| 参照型 | 規約・スタイルガイドなど知識提供 | インラインで知識として効かせる |

## サブエージェントテンプレート

### フロントマター

最小構成は `name` と `description` のみ。

```yaml
---
name: agent-name
description: 委譲条件を具体的に書く
---
```

オプションフィールド:

| フィールド | 追加するとき |
|-----------|-------------|
| `tools` | ツールを制限したい場合（**省略すると全ツールを継承**） |
| `model` | コスト最適化したい場合（探索系は `haiku`）。省略で `inherit` |
| `memory` | 会話をまたいで学習を蓄積させたい場合 |

`tools` は**省略するとメイン会話の全ツールを継承**する。読み取り専用のレビュー役など安全性を担保したいエージェントには必ず指定する。

### 本文（システムプロンプト）

本文がそのままシステムプロンプトになるため、構造化することで指示追従性が上がる。

推奨構成:

```
あなたは〇〇の専門家です。   ← 役割（1行）

呼ばれたときの手順:          ← 何をするか
1. ...

チェックリスト / 観点:       ← 何を見るか
- ...

出力フォーマット:             ← どう返すか
- ...
```

見出し（`##`）と「ラベル + コロン」はどちらでも効果は同等。本文が長くなったら `##` に切り替える。

## スキルとエージェントの連携

- エージェント側に `skills:` フィールドを書くと、起動時にそのスキルの全文がコンテキストに注入される
- スキル側に `context: fork` と `agent:` を書くと、タスクとして指定エージェントで隔離実行できる
