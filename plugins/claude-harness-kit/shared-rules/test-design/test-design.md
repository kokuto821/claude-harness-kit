# 3 <面で逃さない>　論理組み合わせテスト
## ドメイン分析テスト
- on
  - 着目している境界値
  - x>=10の場合:10
- off
  - onポイントに隣接する境界値
  - x>=10の場合:9
- in
  - ドメインの条件に合致する値
  - x>=10の場合:15
- out
  - ドメインの条件に合致しない値
  - x>=10の場合:5
- 着目する１つの変数に対してはon/offを変化させ、それ以外はすべてinにしておけば、着目する変数の評価を確実にすることができる。
- タイプが違う者同士で組み合わせる
  - 同じタイプ同士でテストしない
- 例：Binderのドメイン分析テストマトリクス

例題

>基本ダメージ値 ＝（自分の攻撃力 / 2）-（敵の守備力 / 4）
>計算結果がマイナスの場合基本ダメージは0となる
>自分の攻撃力の最大値は100、敵の守備力の最大値は80とする

自分攻撃力: 100 >= player.attack >= 0

on: 100
off: 101
in: 50

敵守備力: 80 >= enemy.defence >= 0

on: 80
off: 81
in: 40

|               |       |   1   |   2   |   4   |   5   |
| :-----------: | :---: | :---: | :---: | :---: | :---: |
| player.attack |  on   |  100  |       |       |       |
|               |  off  |       |  101  |       |       |
|               |  in   |       |       |  50   |  50   |
| enemy.defence |  on   |       |       |  80   |       |
|               |  off  |       |       |       |  81   |
|               |  in   |  40   |  40   |       |       |
|     結果      |       |  40   | error |   5   | error |
