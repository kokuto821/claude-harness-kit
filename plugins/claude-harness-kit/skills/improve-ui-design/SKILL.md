# improve-ui-design

## 概要

既存の UI 実装を `rules/ui-design/` のルールに照らして見直し、配色・余白・角丸・レイアウト・UX の改善点を抽出して適用するタスクスキル。レビュー（指摘のみ）ではなく改善の適用まで行う。

## 手順

### 1. 対象 UI を読む

改善対象のコンポーネント・画面ファイルを読み、現状の構造・スタイルを把握する。

### 2. 索引から該当ルールを読む

`rules/ui-design/README.md`（索引）を読み、以下を取得する。全ファイルは読み込まない。

- 共通: `styling-rule/color.md` / `styling-rule/space-and-radius.md` / `styling-rule/improve-layout.md` / `styling-rule/improve-ui.md`
- 対象 UI に該当する `component/<分類>/<name>.md`

### 3. 改善点を抽出する

手順2で読んだルールに照らして違反・逸脱を洗い出す。観点（基準値はルール参照）: 配色 / 角丸 / 余白・情報密度 / レイアウト / UX。

### 4. 改善を提案・適用する

抽出した改善点を、影響の大きいものから適用する。破壊的な変更や意図が不明な箇所は適用前にユーザーへ確認する。

## 出力

- 改善点リスト（各項目に根拠ルールファイルのパスを併記）。
- 適用後のコード。確認が必要な変更は別途提示する。
