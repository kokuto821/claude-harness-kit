# steering-review

プロジェクトの Claude Code ステアリング構成（CLAUDE.md・rules・skills・subagents・hooks・output styles）を、各手法の公式の意図に照らしてレビューするスキルです。

手法の誤用・逸脱を Critical / Warning / Suggestion で指摘します（改善の適用はしない）。判断基準は `rules/mechanism-selection/selection-rule.md`・`rules/harness-control/harness-rule.md`、事実は `documents/reference/steering-claude-code.md`。人間向けの概要はここ、AI/ハーネス向けの定義は `SKILL.md` にあります。
