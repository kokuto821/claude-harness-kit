# ハーネスエンジニアリング 調査まとめ

**作成日**: 2026-06-04
**カテゴリ**: research
**タグ**: #harness #wire-harness #electrical #automotive #aerospace #manufacturing #quality

## 概要

ハーネスエンジニアリング（Wire Harness Engineering）は、電気信号・電力を効率よく伝達するために、複数のワイヤー・ケーブル・コネクタ・端子・保護材をまとめたアセンブリ（ワイヤーハーネス）を設計・製造する技術分野。自動車・航空宇宙・産業機器・家電など幅広い分野の「電気的バックボーン」として機能する。

---

## ワイヤーハーネスとは

- 複数の電線・コネクタ・端子・スリーブを束ねた組立品
- 電力供給・信号伝達の両方を担う
- 乱雑な配線を整理し、スペース効率・信頼性・安全性を向上させる
- 車両1台あたり数十〜数百本の電線が使われ、電気自動車では特に増加

---

## 主な構成部品

| 部品 | 役割 |
|---|---|
| ワイヤー / ケーブル | 電力・信号の伝送路 |
| コネクタ | 回路間の接続・切り離し |
| 端子（ターミナル） | ワイヤーとコネクタの接合点 |
| 保護スリーブ / チューブ | 振動・熱・摩耗からの保護 |
| テープ / ラップ | 束ねて形状を保持 |
| グロメット | 貫通部のシール・保護 |
| ブラケット / クリップ | 固定・取り回しのサポート |

---

## 設計プロセス

### 1. 要件定義
- 電気仕様（電圧・電流・信号種別）の把握
- 機械的制約（搭載スペース・曲げ半径・温度範囲）の確認
- 適用規格・認証要件の特定

### 2. スキーマティック作成
- 回路図・配線図の作成
- ネットリスト・部品表（BOM）の生成
- CADツール（Zuken E3.series、Capital Harness、Mentor xDX Designerなど）を使用

### 3. 2D / 3D レイアウト設計
- フォームボード（ハーネスボード）上の物理レイアウト
- 3D CADへの統合で搭載性・干渉チェックを実施
- 曲げ半径・固定点・余長（スラック）の設計

### 4. 部品選定
- ワイヤーゲージ（AWG / mm²）・絶縁材質の選定
- コネクタ・端子メーカー仕様との照合
- 軽量化要件に対するアルミ電線・複合材の検討

### 5. プロトタイプ・検証
- First Article Inspection（FAI）の実施
- 電気試験・引っ張り試験・環境試験
- 設計変更フィードバックへの対応

## 製造プロセス

```
1. ワイヤーカット・ストリップ
       ↓
2. 端子圧着（クリンプ）/ はんだ付け
       ↓
3. コネクタへの端子挿入
       ↓
4. フォームボード上での経路取り回し・束線
       ↓
5. テープ巻き・スリーブ装着・グロメット取付
       ↓
6. 電気試験（導通・絶縁・誤配線チェック）
       ↓
7. 外観検査・引っ張り試験
       ↓
8. ラベリング・梱包・出荷
```

## 主要材料と選定基準

### ワイヤー絶縁材
| 材料 | 特性 | 用途 |
|---|---|---|
| PVC | 低コスト・一般用途 | 家電・一般車両 |
| XLPE（架橋ポリエチレン） | 耐熱・耐薬品 | 自動車・産業機器 |
| PTFE（フッ素樹脂） | 高耐熱・高周波特性 | 航空宇宙・高温環境 |
| シリコーン | 柔軟性・広温度範囲 | 医療・高温機器 |

### 導体材料
- **銅**：標準的な選択。高導電性・加工容易
- **アルミ**：軽量（銅の約1/3重量）。EV・航空での採用が増加
- **銀メッキ銅**：高周波・高信頼性用途

## 品質管理・規格

### IPC/WHMA-A-620（最重要規格）
- ケーブル・ワイヤーハーネスアセンブリの唯一の業界コンセンサス規格
- IPC（電子工業会）と WHMA（ワイヤーハーネス製造業者協会）が共同策定
- 最新版：**IPC/WHMA-A-620F（2025年版）**
- 700枚以上のカラー写真で合否判定基準を視覚的に定義

#### 品質クラス
| クラス | 対象 | 検査水準 |
|---|---|---|
| Class 1 | 一般民生品 | 最低限の検査 |
| Class 2 | 産業・通信機器 | AQLサンプリング検査 |
| Class 3 | 航空宇宙・医療・軍事 | 100%全数検査＋完全記録 |

### 主な試験項目
- **導通試験**：断線・短絡・誤配線の100%チェック
- **圧着高さ測定**：マイクロメータによる寸法確認
- **引っ張り試験（Pull Test）**：端子保持力の確認
- **圧着力モニタリング（CFM）**：圧着工程のリアルタイム監視
- **耐電圧試験**：絶縁性能の確認
- **環境試験**：耐熱・耐振動・耐湿性の評価

### その他の関連規格
- **ISO 9001**：品質マネジメントシステム
- **IATF 16949**：自動車産業品質規格
- **AS9100**：航空宇宙品質規格

## 業界別応用

### 自動車
- エンジン・ライト・センサー・インフォテインメントを接続
- 1台の車両に約1,500〜3,000本の電線（総延長3km超）
- EV・HEVでは高電圧ハーネス（400V / 800Vシステム）が必須
- 業界最大の市場：グローバル市場規模は数兆円規模

### 航空宇宙
- 軽量化が最優先（アルミ電線・複合材の採用）
- 高い信頼性要件（AS9100 / MIL規格準拠）
- 電磁シールド（EMI対策）が重要
- 機体1機あたり数百km以上の電線を使用する場合も

### 産業機器・ロボット
- 可動部への対応（フレキシブルケーブル・耐屈曲仕様）
- 防塵・防水（IP規格対応）
- 高温・化学薬品環境への耐性

### 医療機器
- 生体適合性・無毒性材料の使用
- Class 3相当の品質管理（FDA規制対応）
- 洗浄・滅菌への耐性

## 2026年の主要トレンド

### 1. 電動化対応
- EV・PHEVの普及で高電圧ハーネス需要が急増
- 800Vシステム向けの絶縁・安全設計が重要課題

### 2. 軽量化
- アルミ電線・薄肉絶縁材の採用拡大
- 自動車の燃費・航続距離向上への貢献

### 3. 製造の自動化
- ワイヤーカット・ストリップの自動化は普及済み
- 圧着・挿入・テープ巻きの自動化が進行中
- ロボットアームによるハーネス組立の実用化

### 4. モジュラー設計
- バリアント対応のモジュール化でカスタマイズ時間を短縮
- プラットフォーム共有化による開発コスト削減

### 5. デジタルツイン・シミュレーション
- 3D CAD統合による搭載性検証の前倒し
- 製造前の干渉チェック・経路最適化

### 6. 高速データ伝送対応
- LVDS・Ethernet（100BASE-T1 / 1000BASE-T1）対応ハーネス
- 自動運転・ADAS向けの高帯域配線設計

---

## 設計上の重要ポイント

- **曲げ半径**：ワイヤー外径の最低6〜10倍を確保（断線防止）
- **固定点**：振動・摩耗を防ぐ適切な間隔でのクリップ固定
- **余長（スラック）**：組付け・メンテナンス時の作業性確保
- **ラベリング**：各ハーネスの識別番号・端末表示
- **熱管理**：熱源近傍での耐熱スリーブ・ルーティング変更
